# Noirgram — план переделки Telegram Web A в десктоп-клиент

База: Telegram Web A 12.0.48 (коммит `Upstream` в git). Оболочка: Tauri 2 (`tauri/`).
Цель: нативный `.exe` для Windows с брендингом Noirgram и дизайном «ближе к Swiftgram»:
тёмный «noir» холст, стеклянные плавающие панели, пружинная анимация, фирменный голубой.

## Бренд

| Токен | Цвет | Где |
|---|---|---|
| Noir Blue | `#87A6DF` | Акцент: ссылки, активные иконки, переключатели, фокус |
| Noir Blue Deep | `#4A649E` | Свои сообщения, выбранный чат, primary-кнопки (белый текст ≥ 4.5:1) |
| Silver | `#D5D6D8` | Глиф логотипа, вторичный акцент на тёмном |
| Noir 0 / 1 / 2 | `#0B0C10` / `#121319` / `#1A1C24` | Фоны (холст, колонки, поднятые поверхности) |

Логотип: `src/assets/noirgram-logo.svg` (стрелка-самолётик Silver на Noir Blue). Иконки приложения генерируются из
`tauri/icons/noirgram-icon.svg` через `npx tauri icon`.

## Принцип изменений

- Свои стили — в `src/styles/noirgram/*.scss` (подключаются последними, без `@layer`), чтобы правки
  апстрима сливались без конфликтов. Точечные правки компонентов — только там, где нужна логика.
- Цвета обеих тем — через `src/styles/themes.json` (анимируемое переключение тем).
- Всё, что специфично для десктопа, завязано на `body.is-tauri` / `IS_TAURI`.
- Настройки, которые нужны до появления окна (прокси, трей, загрузки), хранит оболочка:
  `%APPDATA%\app.noirgram.desktop\desktop-settings.json` и `download-settings.json`.
- Строки Noirgram: английский в `fallback.strings`, русский в `src/util/localization/noirgramStrings.ts`
  (языковые пакеты Telegram приходят с сервера и наших ключей не знают).

## Сборка

- Разработка: `npm run tauri:dev` (фронтенд с Vite на `localhost:1234`).
- Релиз: `npm run tauri:build` → `tauri/target/release/bundle/nsis/Noirgram_<версия>_x64-setup.exe`.
  Фронтенд встроен в exe и раздаётся встроенным сервером на `http://localhost:47833` (Service Worker
  работает только на http(s)-origin; порт фиксирован — от него зависит хранилище сессии).
- `dist/` не коммитится: в сборке ключи API из `.env`.

2. [x] Брендинг: название в окне/трее/установщике/`Cargo.toml`, identifier `app.noirgram.desktop`,

## Фаза 2 — окна и десктоп-UX

- [x] Мини-аппы в отдельном нативном окне, как в Telegram Desktop: мост `TelegramWebviewProxy`
  (`tauri/src/mini_app_bridge.js`), нижние кнопки и «Назад» рисуются в окне, остальное — через основное окно.
  Окно мини-аппа не может перейти на origin приложения.
- [x] Загрузки молча сохраняются в `Загрузки\Noirgram` (без дублей имён), тост «Показать в папке».
- [x] Своя папка загрузок (системный диалог, сброс к стандартной) и «Спрашивать, куда сохранять».
- [x] «Сохранить как…» в контекстном меню сообщения с файлом/медиа.
- [x] Большие файлы качаются через Service Worker в окне приложения (без отдельного всплывающего окна).
- [x] Прокси SOCKS5/HTTP для всего клиента (WebView2 `--proxy-server`, применяется после перезапуска).
- [x] WebView2: GPU-растеризация, без троттлинга в фоне (соединение живёт, пока окно свёрнуто в трей).
- [x] Узкое окно (мобильная раскладка) и `--vh` учитывают тайтлбар; тонкие скроллбары только при наведении.
- [x] Пружинный отклик на нажатие (кнопки, строки списков, пункты меню), кнопки без капса.
- [x] «Открыть в новом окне» в контекстном меню чата (было в Web A, работает через `open_new_window`).
- [x] Горячие клавиши Telegram Desktop: Ctrl+K, Ctrl+Shift+F, Ctrl+F, Ctrl+Tab/Ctrl+Shift+Tab,
  Ctrl+PgUp/PgDn, Ctrl+1…8 чаты, Ctrl+Shift+1…9 папки, Ctrl+0 Избранное, Ctrl+9 архив, Ctrl+, настройки,
  Ctrl+L блокировка, Ctrl+W закрыть, Ctrl+M свернуть, F11 полный экран, Ctrl+Q выход; шпаргалка в настройках.
- [x] Автозапуск (стартует свёрнутым в трей), «закрывать в трей» как настройка, повторный запуск
  возвращает окно из трея, окно и его размер запоминаются.
- [ ] Нативные уведомления Windows с кнопками «Ответить» / «Прочитано» (нужен свой toast-активатор).
- [ ] Перетаскивание файла из чата в Проводник.
- [ ] Отдельное окно просмотра медиа.
- [ ] Контекстные меню компактнее, подменю по ховеру.
